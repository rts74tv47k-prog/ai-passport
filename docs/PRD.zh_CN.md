# 私人 AI 伴侣 · 产品需求文档（PRD）

| 项目 | 内容 |
| --- | --- |
| 文档版本 | v1.1 |
| 文档状态 | 已确认，作为 MVP 开发唯一依据 |
| 目标硬件 | FoloToy AI Passport（ESP32-C3） |
| 开发基线 | Fork 官方仓库，分支 feature/companion-mvp |

## 1. 产品定义

一句话：一个长在 AI Passport 上的私人 AI 伴侣——基于人设与我日常对话，并随时用语音把随想沉淀为可导出的个人知识库。

两条核心动线：

- 聊（陪伴）：人设驱动的大模型对话，语音 + 文字双通道回复
- 记（沉淀）：按键说话 → 自动转写 → AI 自动分类（支持语音新建分类）→ 本地知识库 → 局域网一键导出 txt

产品气质：极简、克制、私人。它是"我日常沟通的一个小工具"，不是平台，不做社交。

## 2. 用户与场景

- 用户：单用户（本人），无账号系统
- 使用环境：有 Wi-Fi（含手机热点）；首次联网走官方蓝牙配网方案
- 典型场景：碎片时间闲聊；打完球路上长按记一句心得；睡前看书口述存入读书分类；周末电脑上导出 txt 归档

## 3. 硬件平台与关键约束

| 硬件能力 | 规格 | 对产品的影响 |
| --- | --- | --- |
| 屏幕 | 240×320 竖屏 | UI 为小屏定制，中文需专用字体 |
| 按键 | UP / DOWN / OK（短按/长按/双击可识别） | 全部交互由三键完成 |
| 音频 | 麦克风 + 扬声器 | 语音输入与播报 |
| 联网 | Wi-Fi 2.4G + BLE | ASR/LLM/TTS 均走云端 API |
| 存储 | 8MB Flash，无 PSRAM | 只存文字，语音即焚 |
| 电池 | 内置电量计 | 电量角标常显 |

关键约束及应对：

1. 必须联网：语音识别、对话、合成都在云端。离线时仅保留浏览已存记录，聊天/记录入口给出明确离线提示。
2. 不做语音唤醒：ESP32-C3 算力与功耗不支持麦克风常开监听。按键即唤醒。
3. UI 必须原创：遵循官方规则，禁止复用基线测试菜单/页面；可复用 BSP 驱动与非 UI 逻辑。
4. 内存精打细算：无 PSRAM，形象用低成本帧动画，单块内存分配不超过 8KB（录音缓冲按流式写盘方案另计）。

## 4. 功能需求

### 4.1 主页（默认界面）

- 固定的伴侣形象（与人设解耦）：抽象、极简风格
- idle 动效：呼吸 + 偶尔眨眼
- 底部气泡区：显示最近一条回复
- 右上角状态角标：电量（常显，读取失败时优雅隐藏）、Wi-Fi 状态

### 4.2 聊天（人设对话）

- 人设为一段文本提示词，经网页端编辑（设备无键盘）
- 流程：OK 短按开始 → 形象切倾听动效 → 再短按结束 → 屏幕气泡 + 语音同步回复 → 形象回应动效
- 上下文：默认保留最近 5 轮对话（默认值，可调）
- 聊天历史不持久化：只有"记录"动线的产物进入知识库

### 4.3 语音记录（知识库写入）

四态流程：

1. 倾听态（独立页面）：长按 OK 进入。形象侧耳动效 + 音量波动条 + 录音计时。因长按阈值（约 0.5s），按下后短暂延迟进入属正常。
2. 处理态：松手后波形停止，显示"识别中…"。转写与分类判断一次调用完成。
3. 确认态（独立页面）：显示转写文本 + AI 建议分类。UP / DOWN 切换分类（新建分类排最前，按最近使用排序）；OK 短按 = 确认存入，返回主页；OK 长按 = 丢弃，返回主页。无超时自动确认，一直等待；闲置后屏幕自动变暗。
4. 完成：返回主页，轻量成功反馈（形象点头或短提示音）。

单条录音上限 60 秒（默认值），到时自动截断并提示。

### 4.4 分类系统

- 初始三类：日常 / 网球 / 读书
- AI 自动判断：转写文本 + 当前分类列表一并送大模型，一次调用完成"归入已有 / 新建 / 默认日常"
- 语音新建示例："记到健身分类，今天做了三十个俯卧撑" → 新建「健身」并归入
- 安全阀：新建分类名必然出现在确认页，转写错误可见、可丢弃
- 分类列表按最近使用排序；网页端可查看/新建/改名

### 4.5 浏览页

- 主页按 UP 或 DOWN 进入
- UP / DOWN 翻看历史记录，按分类分组显示（时间 + 正文）
- OK 短按：展开/收起长文本；OK 长按：返回主页
- 纯查看；整理靠导出后在电脑完成

### 4.6 局域网网页端

设备与手机/电脑同一 Wi-Fi，浏览器访问设备地址：

| 功能 | 说明 |
| --- | --- |
| Wi-Fi 配置 | 设置 STA 凭据（也支持设备端配网入口，见阶段 3） |
| 人设编辑 | 大文本框，保存即生效 |
| API Key 设置 | 智谱 API Key，存设备 NVS，不进代码仓库 |
| 分类管理 | 查看 / 新建 / 改名 |
| 记录浏览 | 全量记录分页浏览 |
| 导出 txt | 按分类或全量导出，带 BOM 的 UTF-8 |
| 存储状态 | 显示已用容量，接近上限提示导出清理 |

### 4.7 全局规则

- 聊天与录音互斥，一个进行中不可开始另一个
- 任何异常（离线、API 失败）不惊扰，用状态提示表达，浏览功能不受影响

## 6. 数据规格

### 6.1 记录字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| 时间戳 | datetime | 精确到分钟（SNTP 对时） |
| 分类 | text | 分类名 |
| 正文 | text | 转写原文 |
| 序号 | int | 自增，保证导出有序 |

### 6.2 导出格式

文件名 `passport-notes-YYYY-MM-DD.txt`，带 BOM 的 UTF-8：

```text
== 日常 ==
[09-29 08:32] 今天多云，散步时想到一个产品点子……
[09-29 21:10] 有点累，早点睡

== 网球 ==
[09-29 19:45] 反手总下网，教练说引拍太晚，下次练提前转肩

== 读书 ==
[09-29 22:30] 《xxx》第三章：作者论证了……
```

### 6.3 存储机制（按阶段 1 已提交实现，勿重写）

- storage 分区位于 Flash 尾部（0x410000，约 3.9MB），ESP-IDF 内置 FAT + 磨损均衡
- 记录按条追加；删除用双标记位（写一半断电可重删）；坏尾记录下次打开时截断
- 不保存原始音频；单次内存分配 ≤ 8KB
- 估算容量约 3000 条；网页端显示用量，接近上限提示导出清理

### 6.4 隐私

- 记录仅存设备本地；内容仅在处理时发送至所选 AI API
- 不做云存储，不传第三方；网页端仅局域网可访问
- API Key 存于设备 NVS，不入代码库；日志不打印对话与记录正文（只记 id/长度/错误码）

## 7. 体验原则

1. 越简单越好：设备端仅 3 个页面 + 1 个网页端
2. 克制的视觉：极简抽象形象，无多余装饰
3. 反馈即时：每个按键动作必有视觉回应
4. 静默降级：异常不惊扰，用状态与提示表达

## 8. 非目标（v1 明确不做）

| 项目 | 原因 |
| --- | --- |
| 语音唤醒词 | C3 算力/功耗不支持常开监听 |
| 离线聊天/记录 | ASR/LLM 依赖云端 |
| 云端同步/备份 | 与隐私定位冲突，局域网导出已满足 |
| 原始音频存储 | 存储仅够文字 |
| 记录编辑 | 仅有"丢弃"；整理靠导出后处理 |
| 记录搜索 | v2 考虑 |

## 9. 验收标准（MVP 完成的定义）

- [ ] 说 1 分钟话 → 松手 → 确认页出现，全程 ≤ 10 秒
- [ ] 归入已有分类、语音新建分类、改分类、丢弃四条路径可用
- [ ] 每条记录均需手动 OK 确认；确认页无超时自动保存
- [ ] 断电重启后记录与分类完好
- [ ] 浏览器可编辑人设、管理分类、导出 txt；txt 在微信/记事本打开不乱码
- [ ] 离线时聊天/记录有明确提示，浏览可用
- [ ] 电量角标常显；低于 20% 提醒
- [ ] UI 为原创设计，未复用基线测试菜单/页面

## 10. 技术选型

| 事项 | 方案 |
| --- | --- |
| AI API | 智谱 bigmodel.cn：glm-asr（语音识别）/ glm-4-flash（对话+分类）/ cogtts（语音合成，响应可能为 wav 或 mp3；播放器仅支持 wav，非 wav 跳过播报只显示文字） |
| 配网 | 阶段 3 定：优先复用官方方案，兜底 SoftAP 网页配网 |
| UI 框架 | LVGL（官方基线），中文字体用 LVGL 内置 CJK 字体 |
| 固件 | ESP-IDF 5.5.3，复用 BSP 驱动，应用代码在 main/ |
| 版本管理 | GitHub Fork，feature/companion-mvp 分支，迭代打 tag |
